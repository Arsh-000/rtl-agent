The design

An 8-bit up/down counter whose value is output in Gray code. - On every rising clock edge where 'en' is 1, the internal binary count goes up by 1 if 'up' is 1, or down by 1 if 'up' is 0. It wraps around (255 + 1 = 0, 0 - 1 = 255). - 'rst' is an active-high synchronous reset that sets the count to 0. - 'gray' is the current count converted to Gray code: gray = count ^ (count >> 1). It must be a registered output (it changes only on clock edges), and it changes on the SAME clock edge as the count: after every edge, gray already shows the Gray code of the new count (no extra cycle of delay). After reset, gray is 0.

// ===== gray_counter.v =====
module gray_counter (
    input  wire       clk,
    input  wire       rst,
    input  wire       en,
    input  wire       up,
    output reg  [7:0] gray
);
    reg  [7:0] count;
    wire [7:0] next = up ? count + 8'd1 : count - 8'd1;

    always @(posedge clk) begin
        if (rst) begin
            count <= 8'd0;
            gray  <= 8'd0;
        end else if (en) begin
            count <= next;
            gray  <= next ^ (next >> 1);
        end
    end
endmodule

Round 3 · improve · kept · look-ahead registers for count+1 and count-1 so the Gray output needs only XOR + select

LLM diagnosis / plan: The best version (round 2) still misses timing by a small margin. Its critical path is count register -> 8-bit increment/decrement carry chain -> Gray XOR -> select on 'up' -> gray register. Keep count+1 and count-1 ready in look-ahead registers (inc_r, dec_r). Then the gray register only needs one XOR and a 2:1 select, and the carry chains move to the inc_r/dec_r registers, which have a whole cycle with no XOR after them. Outputs are unchanged cycle for cycle; it costs 16 extra flip-flops.
